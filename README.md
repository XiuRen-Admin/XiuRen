### 掉以轻心: This project is in active development！

### What is this ? / 这个是什么？
I created with time a sophisticated folder structure for my collection, which allowed me additionally to list all issues by model, photographer, label and highlight special ones. I also have quick links to favourite models in the root folder.
I wrote a Python script, to create this structure as a backup, as a way to move it somewhere else and potentially for others to use.

I am adding each issue by hand. This is a slow process, but allows me to avoid common issues faced by others (e. g. hdleg) such as models, who changed their names often, collections (which do not name the featured models) and also grasp the history of the platform.

I am currently still in the »founding age« (XR0001-XR1000) and intend to publish the first version, when having completed it. I also expect the other »ages« to be done quicker, as less and less subseries will exist to handle in parallel.

I also intend to include at least TGod, as this label shares many models and photographers and even series (DK Girl, YouMiHui) with 秀人。

谢谢你们！
